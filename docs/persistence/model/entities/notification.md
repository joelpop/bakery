# NotificationEntity (Superseded)

> **This entity was never implemented.** The originally planned user-to-user notification system has been superseded by the order messaging system built on `OrderActivityEntity`.
>
> Staff communication happens in the context of orders via the activity timeline, with unread tracking and cross-session push notifications via `MessageBroadcaster`.
>
> See [Messaging](../../../features/messaging.md) for details on the implemented system.
